# MailState Sync

## 概要

自身のDropboxを使ってPOP3メールの既読状態と移動先を同期します。利用者自身のDropbox App keyが必要です。

## 説明

複数PCに既にあるPOP3メールの既読・未読状態と、同じアカウント内での移動先フォルダーを、自身のDropbox内のJSONファイルを通じて同期します。移動先フォルダーがない場合は作成します。

Thunderbirdのアドオン管理画面から設定を開き、プライバシーの説明を確認して同意し、対象POP3アカウントを選んで同期を有効化してください。Dropbox APIアプリをApp folder方式で作成し、設定画面に記載された3つの権限を有効にします。App keyとDropboxの認証コードで接続し、全PCで同じDropboxアプリ・アカウントを使います。初回は正しい配置のPCで総スキャンし、別PCで取得・反映してください。詳しい設定手順はアドオン内にあります。Dropboxアカウントと自身で作成するAPIアプリが必要ですが、開発者が発行する専用キーや限定会員資格は不要です。

選択したアカウントのメールアドレス、Message-ID、既読状態、フォルダー名・パス・メール件数、変更履歴、ランダムなクライアント識別子をHTTPSでDropboxへ送信します。これらには個人情報が含まれる場合があります。同期データと認証トークンはThunderbirdプロファイルに保存します。メール本文・件名・添付ファイル・アドレス帳・メールパスワードは送信しません。開発者への利用状況送信もありません。公開ページと設定画面のプライバシーポリシーをご確認ください。

既読・未読の同時変更は既読を優先し、移動先の競合は変更履歴と時刻で解決します。PCの時計を正確にしてください。DownloadsへのJSONミラー保存と、両側で空と確認したカスタムフォルダーの削除は任意機能で、初期状態では無効です。有効化すると追加権限を求めます。標準フォルダーや子フォルダーのあるフォルダーは削除しません。

Thunderbird 128以降に対応し、同じメールアドレスのPOP3アカウントを使用します。メール本文のPC間コピー、削除・タグ・スターの同期、IMAP、別アカウント間や「ローカルフォルダー」への移動は対象外です。Message-IDが一致するメールが必要です。自動同期にはThunderbirdの起動が必要です。Dropboxに保存するJSONは読み取り可能で、アドオン独自のエンドツーエンド暗号化は行いません。メールバックアップの代わりにはなりません。

設定から同期停止・同意撤回・切断・ローカル保存データの削除ができます。既存のDropboxファイルと出力ミラーは手動で削除するまで残ります。ローカル切断だけではDropbox側の認証は取り消されないため、必要に応じてDropboxの接続済みアプリから解除してください。Dropbox自身の利用条件と容量制限が適用されます。アドオン自体に課金・広告・アフィリエイト機能はありません。Dropbox・Thunderbirdの公式製品ではありません。

## 0.9.0の変更

公開に向け、明示的同意、厳密な対象アカウント指定、任意権限、日本語・英語の設定画面、プライバシー管理、Dropbox認証の自動更新、再現可能なパッケージ作成を整備しました。既存の利用者も同意を保存するまで同期を再開しません。0.8.1のメール移動修正を含みます。
