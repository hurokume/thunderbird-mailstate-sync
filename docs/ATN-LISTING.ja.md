# MailState Sync

## 概要

POP3メールの既読・未読と移動先フォルダーをDropbox経由で同期します。Dropbox App keyが必要です。

## 説明

自宅と外出先など、複数のPCで同じPOP3メールを受信している場合に使うアドオンです。一方のPCでメールを読むと、もう一方でも既読になります。同じアカウント内でメールを移動したときは、移動先も同期します。移動先のフォルダーがなければ作成します。

各PCに同じメールがあることが前提です。本文や添付ファイルのコピー、メールの削除・タグ・スターの同期には対応していません。IMAP、別アカウント間の移動、「ローカルフォルダー」への移動も対象外です。

### 設定

Thunderbird 128以降と、Dropboxアカウントが必要です。

1. Dropbox App Consoleで、Scoped access、App folderを選んでAPIアプリを作成します。Permissionsで files.metadata.read、files.content.read、files.content.write を有効にし、Submitで保存します。
2. アドオンの設定で、対象のPOP3アカウントを選び、同期を有効にします。「データの送信」を確認して同意にチェックを入れます。
3. App keyを貼り付けて「保存してDropboxで認証」を押し、Dropboxが表示した認証コードで接続します。
4. 各PCで同じDropboxアプリ・Dropboxアカウントを使います。POP3アカウントのメールアドレスも揃えてください。
5. 基準にしたいPCで「このPCのメールを確認して送信」、他のPCで「Dropboxの変更を反映」を実行します。

開発者が発行するキーや会員登録は不要です。

### 同期の動作

Thunderbirdの起動中に変更を送信し、自動反映が有効ならDropboxの変更を約1分ごとに確認します。メールはMessage-IDで照合するため、これが一致するコピーが必要です。Message-IDがないメールは同期できず、重複している場合は複数のメールに反映されることがあります。

既読・未読を別のPCで同時に変更した場合は既読を優先します。移動先が食い違う場合は変更履歴と時刻で決めるため、PCの時計を合わせてください。

ダウンロードフォルダーへのJSON出力と、空フォルダーの削除は詳細設定から有効にできます。どちらも初期状態では無効で、有効にすると追加の権限を求めます。フォルダーを削除するのは同期元・同期先ともに空の場合だけです。標準フォルダーや子フォルダーがあるものは削除しません。

### 保存するデータ

Dropboxへ送るのは、対象アカウントのメールアドレス、Message-ID、既読・未読、フォルダー名・パス・メール件数、変更履歴、端末ごとの識別子です。フォルダー名などに個人情報が含まれる場合があります。通信にはHTTPSを使い、同期データと認証情報はThunderbirdプロファイルにも保存します。

本文・件名・添付ファイル・アドレス帳・メールパスワードは送信しません。開発者への利用状況の送信もありません。詳しい取り扱いは、公開ページと設定画面のプライバシーポリシーに記載しています。

Dropbox上の同期ファイルは読み取り可能なJSONです。アドオン独自のエンドツーエンド暗号化はありません。このファイルからメール本文を復元することはできません。

### 同期をやめるとき

「同期を有効にする」のチェックを外して保存します。同意も外して保存すると、このPCの認証情報を削除します。設定画面から切断や設定・同期データの削除もできます。

Dropboxのファイルと出力済みのJSONは残ります。不要になったら、全PCで同期を止めてから手動で削除してください。Dropbox側のアクセス許可は、Dropboxの「接続済みアプリ」から取り消せます。

Dropboxの利用条件と容量制限が適用されます。アドオン自体に課金・広告・アフィリエイト機能はありません。Dropbox・Thunderbirdの公式製品ではありません。

## 0.9.0の変更

日本語・英語の設定画面、データ送信への同意、対象アカウントの選択、保存データの削除を追加しました。Dropbox認証の自動更新に対応し、JSON出力と空フォルダー削除は初期状態で無効にしました。0.8.1のメール移動の修正も含みます。

更新後は、データ送信に同意して設定を保存すると同期を再開できます。
